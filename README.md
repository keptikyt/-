## Как использовать (Русская версия)

### Шаги настройки:
1. **Замените токен бота**  
   В строке `TOKEN = "ВАШ_ТОКЕН_БОТА"` укажите реальный токен от @BotFather

2. **Подготовьте видеофайл**  
   - Поместите видео в ту же папку, где находится бот
   - Назовите файл `recroll.mp4` (или измените название в `VIDEO_FILE`)

3. **Установите зависимости**  
   ```bash
   pip install pyTelegramBotAPI
   ```

4. **Запустите бота**  
   ```bash
   python bot.py
   ```

### Особенности бота:
- **Мгновенная отправка видео** с поддержкой потокового воспроизведения
- **Информация о пользователе** в подписи к видео:
  - Имя пользователя
  - Юзернейм
  - ID
  - Время запуска
- **Полное логирование** в файл `bot_log.log` и консоль
  - **Проверка перед запуском**:
  - Наличие токена
  - Наличие видеофайла
- **Обработка ошибок** с понятными сообщениями для пользователя
